# homebrew-perch

Homebrew tap for [perch](https://github.com/upsertco/perch) — a real-time terminal dashboard for git changes.

## Install

```bash
brew tap upsertco/perch
brew install perch
```

## Update

```bash
brew update
brew upgrade perch
```

## Uninstall

```bash
brew uninstall perch
brew untap upsertco/perch
```
